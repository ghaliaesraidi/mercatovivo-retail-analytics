# AI use disclosure

AI was used as a learning and production assistant for:

- designing the fictional business case and deterministic dataset generator;
- explaining Excel and SQL concepts during the audit;
- drafting and reviewing data-quality checks, cleaning views, and analysis queries;
- generating a static dashboard preview from validated output tables;
- improving the structure and clarity of the portfolio documentation.

Numerical findings in the showcase were recalculated from the committed raw CSVs by `scripts/analyze_portfolio.mjs`. The raw data are synthetic and contain no real customer information.

The portfolio owner remains responsible for understanding the grain, cleaning rules, KPI definitions, joins, limitations, and recommendations before presenting the project. The repository does not claim that a Power BI `.pbix` file has been built when none is included.
