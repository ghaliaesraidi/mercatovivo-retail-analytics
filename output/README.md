# Validated outputs

These files are regenerated from the committed raw CSVs by `scripts/analyze_portfolio.mjs`.

| File | Purpose |
|---|---|
| `analysis_results.json` | Complete machine-readable validation result used by the dashboard builder |
| `monthly_performance.csv` | Monthly sales, profit, margin, transactions, basket value, and units |
| `store_performance.csv` | Store-level commercial performance |
| `category_performance.csv` | Category sales and profitability |
| `promotion_performance.csv` | Descriptive campaign results |
| `store_targets.csv` | Annual store sales versus target |
| `inventory_store_summary.csv` | Store waste and stockout summary |
| `store_category_exceptions.csv` | Material store-category combinations below chain margin |

The outputs reflect documented cleaning rules. They are analytical results, not replacements for the immutable raw extracts.
